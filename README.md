# E-Shop Order Manager in Python

A beginner-friendly Python program that manages product orders, calculates total costs, and checks eligibility for free shipping based on a specific threshold.

## 🚀 Features
- **Product Details Collection:** Prompts the user for the product name, unit price, and quantity for 3 different products.
- **Cost Calculation:** Computes the total cost per item and accumulates the overall order cost.
- **Free Shipping Check:** Automatically checks if the total order cost reaches or exceeds 100€ and notifies the user accordingly (or displays how much is missing).
- **Code Documentation:** Fully commented step-by-step for educational purposes.

## 💻 How to Run
1. Make sure you have Python installed on your system.
2. Run the script from your terminal:
   python order_manager.py
